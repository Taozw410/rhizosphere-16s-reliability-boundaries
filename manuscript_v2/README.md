# TARE manuscript version 2

This directory contains the restructured manuscript that replaces the original
"method benchmark" framing with a model-and-decision contribution.

## Main narrative

1. Reproducibility, simulator-defined accuracy and cross-project transportability
   are distinct reliability currencies.
2. A four-domain benchmark shows why one method leaderboard is insufficient.
3. TARE-DA turns project design and community structure into a utility interval,
   reliability probability and ALLOW/CONDITIONAL/DENY decision.
4. Internal project holdouts pass the prespecified performance and calibration
   gates.
5. A zero-overlap six-project external panel supports directional robustness
   and conservative abstention but lies outside the development support
   envelope.
