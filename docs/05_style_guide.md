# Style guide

- Language: zh；正式稿件可转英文。
- Target reader: 微生物生态、统计和方法学交叉读者。
- Tone: scientific-question-driven / conservative。
- Terminology: 统一使用“仿真”“已知真值”“项目随机效应”“平台集群”“方法基准”。
- Forbidden expressions: “证明”“真实互作”“统一最优”“完全模拟真实生态”。
- Supervisor preferences: 结论先行；每个数字有唯一来源文件；跨零写证据不足。
- Citation style: 正式稿按目标期刊；内部方案用作者-年份或 DOI。
