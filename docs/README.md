# 论文4：多研究根际微生物组仿真与方法基准

本目录用于规划并执行一项基于现有 45 个根际 16S 项目的多研究仿真研究。

目标不是再报告一次真实数据差异，而是建立一个与现实数据结构相匹配的仿真平台，
在同一已知真值框架下评价差异丰度、core 判定、网络推断和跨研究分类方法。

## 目录

- `sources/数据/`：从现有 45 项目提取的仿真标定参数。
- `scripts/`：仿真器、基准运行器和结果汇总脚本。
- `outputs/`：仿真真值、方法结果、图表和正式结果 JSON。
- `judgment_chain/`：关键判断链和口径变更记录。
- `drafts/`：论文分节草稿。
- `qa_logs/`：方法学、统计和可复现性审查记录。
