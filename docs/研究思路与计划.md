# 论文 4：多研究根际微生物组仿真与方法基准

## 1. 一句话定位

以现有 45 个项目的真实嵌套结构为模板，建立一个已知真值的多研究 16S 仿真平台，量化差异丰度、core、网络和分类方法在项目异质性、稀疏性和技术口径变化下的假阳性与功效。

## 2. 与前 3 篇论文的关系

论文 1 回答真实数据中“有哪些差异”；论文 2 和 3 回答网络/core 结果是否可重复、是否可解释。论文 4 不新增一套真实数据结论，而是回答这些结论在多大范围内能够被现有方法可靠恢复。

本论文应引用前 3 篇提供的参数和失败模式，但不重复其生态结论。

## 3. 科学问题

主问题：

> 在按 45 个根际 16S 项目标定的多研究结构中，常用分析方法能否在控制假阳性的同时保持目标功效，且方法排名是否对项目数、样本量、流行率、深度和扩增区域稳健？

子问题：

1. 差异丰度方法的项目层假阳性是否随研究异质性和零比例升高？
2. core 阈值与传统 occupancy 模型相比，在低流行率 taxa 上的校准和 F1 如何？
3. 网络估计器在已知边结构、组成约束和项目批次下能恢复多少真实边和中心角色？
4. 分类器在参考库偏移、短读长和未见 taxa 条件下何时优于 naive Bayes/IDTAXA？
5. 当前 45 项目需要多少项目数和样本量才能达到预定功效？

## 4. 仿真器设计

### 4.1 两层结构

- 项目/平台层：项目随机截距、可选的作物/环境效应、平台集群相关。
- 样本层：样本深度、组成比例、零膨胀和项目内相关。

### 4.2 至少比较两个生成族

1. 层级 Dirichlet-multinomial / multinomial：
   - 适合组成比例和计数；
   - 可显式控制过离散和零比例。
2. 层级负二项或 zero-inflated negative binomial：
   - 适合高稀疏、过度零；
   - 需要和真实流行率—丰度关系对照。

可选第三族：logistic-normal / copula，用于生成已知相关网络。

### 4.3 必须注入的已知真值

- 生物学效应：作物/农艺系统对比、环境梯度、已知差异 taxa。
- core 状态：真实 core、稀疏边缘 taxa、低丰度但高占据 taxa。
- 网络结构：已知直接边、共同驱动导致的间接相关、无结构 null。
- 分类学真值：属/科标签、参考库外 taxa、低相似度 nearest neighbor。
- 技术扰动：深度、扩增区域、注释率、参考版本和平台批次。

### 4.4 仿真校准门

合成数据必须与真实数据比较以下摘要：

- 特征流行率分布；
- 丰度 rank-abundance；
- 样本深度分布；
- 项目内/项目间方差比；
- Bray–Curtis/Aitchison 距离分布；
- 零计数比例；
- 现有网络边密度和中心性分布。

任何主仿真未通过校准门，不进入方法比较。

## 5. 仿真场景

### 主场景

- 45 项目、每项目 30 样本；
- 真实深度分布；
- 真实零比例和流行率；
- 作物/农艺效应取当前估计的中位效应；
- 无额外参考库偏移。

### 核心敏感性

- 项目数：15、30、45、60；
- 每项目样本数：5、10、30；
- 测序深度：5k、10k、20k、40k；
- 特征流行率：低、中、高分层；
- 效应量：0、小、中、大；
- 扩增区域：V4、V3–V4；
- 分类学误差：0、现实、加倍；
- 平台集群：独立、成对、强批次。

主场景与敏感性场景必须在运行前固定。

## 6. 方法基准

### 差异丰度

- ALDEx2；
- ANCOM-BC2；
- LinDA；
- MaAsLin 或同类线性混合模型；
- 简单 CLR/Wilcoxon 作为诊断基线。

评价：FDR、功效、效应量偏倚、区间覆盖、项目层方向一致性。

### core / occupancy

- 流行率阈值网格；
- 分层 occupancy–detection 模型；
- 简单贝叶斯收缩估计。

评价：core F1、概率校准、检测概率偏差、低丰度 core 的召回。

### 网络

- CLR-Spearman；
- SparCC；
- SPIEC-EASI GLasso；
- SPIEC-EASI MB；
- 可选 GNN link prediction。

评价：边 AUPRC/F1、hub/keystone 恢复、网络相似度、空网络率、计算成本。

### 分类

- naive Bayes / assignTaxonomy 等价基线；
- IDTAXA；
- 轻量 CNN；
- CNN-BERT。

评价：属/科 precision-recall、未见 taxa 召回、参考版本迁移、校准。

## 7. 主终点

共同主排序指标：

1. 在预先指定的目标效应下达到 80% 功效时的 FDR；
2. 在保持名义 FDR 时所需的最小项目数/样本数；
3. core 概率的校准和 F1；
4. 网络直接边的 AUPRC 和 hub 恢复；
5. 分类器在低相似度与参考偏移条件下的校准误差。

禁止只选择方法表现最好的指标。每个方法家族必须有共同主终点和独立敏感性终点。

## 8. 真实数据反向验证

仿真建议必须回到真实 45 项目进行留出检查：

- 项目/平台留出；
- 区域匹配子集；
- 两法一致属子集；
- 已知 core 和网络结果的重建。

仿真结论与真实数据不一致时，不得删除真实数据结果；应将差异写成仿真边界。

## 11. 风险与停止条件

| 风险 | 处理 |
|---|---|
| 仿真器无法同时匹配多个真实摘要 | 优先保留项目异质性、稀疏和深度；降低不现实的网络复杂度承诺 |
| 方法运行不收敛或空网络多 | 记录失败率，失败本身作为主终点，不得只分析成功结果 |
| 计算量超出预算 | 先在 15/30/45 项目三层跑主场景和关键敏感性，再全网格 |
| 结论严重依赖生成族 | 主文只报告跨生成族一致的结论；生成族分歧进入限制 |

停止条件：仿真校准门连续三次失败，应暂停方法比较，先修正生成模型。
