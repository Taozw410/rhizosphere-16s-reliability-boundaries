# Research canon

## Literature facts

- 微生物组方法在稀疏、组成性和多研究背景下可能产生不稳定推断；共现网络的边不能被直接解释为生态相互作用。项目综述依据见 `论文2-网络对比/稿件/paper2_skeleton.md`。
- 分类学标签同时依赖参考数据库、扩增区域和分类器。当前 45 项目中 assignTaxonomy 与 IDTaxa 的读数加权属级一致率为 67.2%，属级注释率差 16.2 个百分点；来源：`分析口径与实验预注册_20261008.md` §22。
- 在跨研究网络比较中，网络相似度与组成相似度高度相关，研究配对和平台配对比作物身份更能预测可重复性；来源：`论文2-网络对比/稿件/paper2_skeleton.md`。
- core 与 hub/keystone 不是可互换概念，且 core–hub 耦合依赖网络估计器；来源：`论文3-core_hub/稿件/结果主线.md`。

## Experimental facts

- 现有数据包含 45 个项目、1,219 个样本、2,024 个属/科级特征；项目样本数为 4–35，来源：`out_analysis/feature_matrix.csv`。
- 特征矩阵约 91.8% 为零；流行率 ≥70% 的特征仅 7 个，≥90% 的特征为 0 个；来源：`sources/数据/45项目数据审计.md`。
- 样本层研究中，研究身份解释的 Aitchison 方差约为 0.5898，作物约为 0.0696；Bray–Curtis 下分别约为 0.6246 与 0.0777；来源：`论文1-45项目分析/分析输出/analysis_summary.md`。
- 作物与水情完全共线，扩增区域与作物部分共线；来源：`论文1-45项目分析/分析输出/analysis_summary.md` 的限制条目。

## Thermodynamic / model facts

- 仿真器是统计模型，不是新的实验测量。
- 主仿真需显式包含项目/平台随机效应、样本深度、组成约束、零膨胀或过离散、分类学检测率和扩增区域差异。
- 仿真参数必须通过与真实数据的摘要统计量对照后方可用于方法比较。

## Supervisor constraints

- 主结论必须给出判断链：数据基础 → 内部效度 → 稳健性 → 外部效度 → 证据等级。
- 所有方法比较必须预注册主终点和敏感性方案。
- 每改一次仿真参数或方法集合，必须重跑全部结果、图表和正文数字。

## Terminology definitions

- 项目：一个 BioProject 或独立公共研究。
- 平台集群：同一团队、试验地、年份/试验系和共享处理结构所定义的更上层独立单位。
- 稀疏结构：特征在样本和项目中的低流行率，而非单纯低测序深度。
- 方法基准：在已知真值下比较估计偏倚、假阳性、功效、区间覆盖和复现性。

## Forbidden claims

- 不得把仿真结果写成真实微生物生态机制。
- 不得把共现关系写成相互作用。
- 不得把作物/水情差异写成因果处理效应。
- 不得声称某方法在所有微生物组场景中最佳。
- 不得用单一仿真生成器决定方法排名而不做参数与生成机制敏感性分析。

## Unresolved claims

- 最适合真实 16S 多研究数据的生成模型仍需比较 Dirichlet-multinomial、层级负二项及 logistic-normal 等方案。
- 网络真值如何同时表示直接与间接关联尚未定稿。
- 分类器仿真中的错误模型是否应完全复用 DADA2 误差矩阵仍需验证。
