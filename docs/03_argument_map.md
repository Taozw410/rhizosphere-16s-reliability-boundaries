# Argument map

## Scientific tension

- What is known: 现有 45 项目已经显示研究层变异占主导，且网络、core 和分类结果均受技术口径影响。
- What is unknown: 在真实稀疏度、组内相关和多研究批次下，常用方法的假阳性、功效和方法排名如何变化。
- Why the gap matters: 如果方法误差与研究异质性同量级，继续增加真实数据结论会把方法不稳定性误写成生态机制。

## Central research question

在按现有 45 个根际 16S 项目标定的多研究仿真中，差异丰度、core 判定、网络推断和跨研究分类方法能否在控制假阳性的同时保持功效和可复现性？

## Central thesis

预计不存在在所有场景下统一最佳的方法；方法表现将由流行率、零比例、项目随机效应、样本量、测序深度、扩增区域和分类学误差共同决定。可靠结论必须同时报告主终点、功效和失败边界。

## Supporting arguments

### Argument 1
- Claim: 真实数据结构要求仿真包含项目层随机效应和分层检测过程。
- Evidence: 研究中方差占主导、项目样本量 4–35、深度分布跨度大。
- Limitation: 参数估计本身带有不确定性，需要参数 bootstrap。

### Argument 2
- Claim: core、网络和分类器的错误机制不同，必须在共同真值框架下分别评价。
- Evidence: core 阈值敏感、网络由组成重述、分类器受参考库影响。
- Limitation: 一个生成器难以同时最真实地覆盖全部数据类型。

### Argument 3
- Claim: 方法排名应通过敏感性网格和真实数据一致性双重校准。
- Evidence: 现有结果在多种设置下稳健与否不同。
- Limitation: 计算量较大，需要分层计算预算。

## Counterarguments / alternative explanations

- 反方：仿真永远无法代表真实生态。回应：本研究不是替代真实数据，而是用真实数据结构校准已知真值；最终建议必须再经过真实数据留出检验。
- 反方：方法比较会受生成器偏置。回应：使用多个生成族、参数不确定性抽样和模型无关的摘要统计校准。
- 反方：现有 45 研究是便利样本。回应：外推范围限定为稀疏根际/土壤 16S 多研究数据。

## Final move

读者应获得一份按场景给出的方法选择表，以及当前 45 项目结论的证据边界，而不是单一“最佳方法”排名。
